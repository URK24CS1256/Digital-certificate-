## Project overview

A web application for managing digital certificates and allowing certificate details to be verified online. The project uses React and Vite for the frontend, Node.js and Express for the backend, and MongoDB with Mongoose for data storage.

## Before running

1. Install a supported Node.js version and make sure MongoDB is available.
2. Copy `backend/.env.example` to `backend/.env` and fill in your own configuration values.
3. Install dependencies in the root, backend, and frontend folders as needed.
4. Read `REVIEW_REPORT.md` for changes applied and security items that still need attention.
